| # | Application | Kind | Type(s) | Where code runs & how delivered | Architecture | Top 3 Qualities (Why) | Filled By |
|---|-------------|------|---------|---------------------------------|--------------|-----------------------|-----------|
| 1 | **ABA Mobile** | Application | Mobile Native, Financial / Enterprise | Client runs on iOS/Android (App Store/Play Store); backend runs in bank private cloud / core banking. | Client-Server (Multi-tier, API Gateway, microservices) | 1. **Security:** Handles financial transactions; breach leads to monetary theft.<br>2. **Availability:** Users need 24/7 transfers; downtime destroys customer trust.<br>3. **Integrity:** Balances and ledger entries must never corrupt. | Chan Dara |
| 2 | **Telegram** | Application | Cross-platform (Desktop, Mobile Native, Web SPA) | Client on phone/desktop (Stores/direct download); cloud server clusters distributed globally. | Decentralized Client-Server with multi-datacenter replication | 1. **Performance:** Message delivery must be sub-second globally.<br>2. **Availability:** Outages interrupt millions of critical communications.<br>3. **Security:** End-to-end secret chats protect user privacy from interception. | Sokha Pich |
| 3 | **Car ABS Controller** | System | Embedded Real-Time, Safety-Critical | Microcontroller ECU inside vehicle braking system; firmware flashed at factory / authorized dealer. | Embedded closed-loop feedback controller (Sensors -> ECU -> Actuators) | 1. **Safety:** Failure to release lockup causes vehicle crash and loss of life.<br>2. **Timing/Predictability:** Must react within milliseconds (hard deadline).<br>3. **Reliability:** Must operate under extreme vibration, temperature, and electrical noise. | Minea Heng |
| 4 | **Moodle at ITC** | Application | Web MPA (Multi-Page App), Educational LMS | Server runs on ITC campus VM (Linux/PHP/MySQL); accessed via web browser over HTTPS. | Traditional Three-Tier (Web browser -> Apache/PHP -> MariaDB) | 1. **Availability:** If down during exams/quizzes, hundreds of students cannot submit.<br>2. **Usability:** Complex navigation confuses students submitting lab assignments.<br>3. **Security:** Protects student grades and exam questions from unauthorized edits. | Bopha Keo |
| 5 | **Mobile Legends** | Application | Mobile Game, Real-Time Multiplayer | Client runs on Android/iOS (OpenGL/Vulkan rendering); dedicated game servers match and sync state. | Client-Server with authoritative state server and UDP game sync | 1. **Performance (Low Latency):** High ping (>100ms) causes game lag and unfair deaths.<br>2. **Availability:** Matchmaking servers must remain online during peak evening hours.<br>3. **Fairness/Security:** Anti-cheat detection prevents memory injection and radar hacks. | Ratanak Lim |

### Biggest Difference We Found:
The ABS controller is a **hard real-time safety-critical system** where a timing delay of even 50ms can cause fatal accidents, whereas Moodle and Telegram are **soft real-time or best-effort client-server systems** where a small network delay merely causes user annoyance rather than physical catastrophe.
